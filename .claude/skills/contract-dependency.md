# 스킬: contract-dependency (계약서 조항 의존성 분석)

## 역할
계약서 내 조항 간 의존관계를 분석하여 연결망(dependency graph)을 구축하고,
특정 조항 변경 시 연쇄 영향을 시뮬레이션한다.

## 트리거 조건
- 계약서 파일(PDF/DOCX/TXT)이 입력되고 의존성 분석이 요청될 때
- 특정 조항 수정 시 영향 범위 파악이 필요할 때
- 복수 계약서 간 조건 충돌 여부 확인 시

---

## 분석 3단계

### [1단계] 조항 파싱 및 분류

계약서를 입력받아 조항을 구조화한다.

**파싱 대상 유형**:

| 유형 | 설명 | 예시 |
|------|------|------|
| `DEFINITION` | 정의 조항 — 다른 조항에서 참조되는 용어를 정의 | "제1조 (정의)" |
| `OBLIGATION` | 의무 조항 — 당사자 의무·이행 조건 | "제5조 (대금 지급)" |
| `CONDITION` | 조건부 조항 — 선행조건·해제조건 | "제8조 (선행조건)" |
| `REMEDY` | 구제 조항 — 위반 시 권리구제·손해배상 | "제12조 (손해배상)" |
| `TERMINATION` | 종료 조항 — 계약 해지·해제 사유 | "제15조 (해지)" |
| `FINANCIAL` | 금융 조항 — 금액·이율·환율·지급조건 | "제6조 (이자)" |
| `GOVERNANCE` | 지배구조 조항 — 의결권·이사회·승인 | "제20조 (이사회)" |
| `DISPUTE` | 분쟁 조항 — 준거법·중재·관할 | "제25조 (분쟁해결)" |

**출력 (JSON)**:
```json
{
  "clauses": [
    {
      "id": "c001",
      "article": "제1조",
      "title": "정의",
      "type": "DEFINITION",
      "defined_terms": ["사업주", "대주단", "완공일"],
      "raw_text": "..."
    }
  ]
}
```

---

### [2단계] 의존관계 추출

조항 간 연결을 세 가지 방식으로 탐지한다.

#### 2-A. 명시적 교차참조 (Cross-Reference)
조항 본문에서 다른 조항을 직접 언급하는 경우.

```
"제10조에 따라 …" → c001 → c010 (CROSS_REF)
"본 계약 제3조 (나)항의 조건이 충족될 경우" → CONDITION_REF
```

#### 2-B. 정의 용어 사용 (Term Usage)
`DEFINITION` 조항에서 정의된 용어가 다른 조항에서 사용되는 경우.

```
정의: "완공일" (c001)
사용: 제8조 "완공일로부터 30일 이내" (c008) → c001 → c008 (TERM_USAGE)
```

#### 2-C. 논리적 의존 (Logical Dependency)
명시적 참조는 없으나 한 조항의 효력이 다른 조항의 내용에 종속되는 경우.
LLM이 조항 내용을 읽고 판단.

```
지급조건(c006) ← 이자율(c007): 이자율 변경 시 지급금액 자동 변동
해지사유(c015) ← 의무조항(c005, c009): 의무 위반이 해지 트리거
```

**의존관계 엣지 형식**:
```json
{
  "from": "c001",
  "to": "c008",
  "type": "TERM_USAGE",          // CROSS_REF | TERM_USAGE | LOGICAL_DEP
  "strength": "STRONG",          // STRONG | MEDIUM | WEAK
  "description": "'완공일' 정의가 선행조건 조항의 기준일로 사용됨",
  "bidirectional": false
}
```

**연결 강도 기준**:

| 강도 | 기준 |
|------|------|
| `STRONG` | 정의 변경 시 해당 조항의 법적 효력이 직접 변동 |
| `MEDIUM` | 조건 변경 시 해당 조항의 의무 범위가 달라짐 |
| `WEAK` | 참조는 있으나 독립적 해석 가능 |

---

### [3단계] 변경 영향 시뮬레이션

특정 조항을 변경한다고 가정하고 연쇄 영향을 추적한다.

#### 입력
```
변경 대상: 제6조 (이자율) — LIBOR → SOFR 변경
```

#### 처리 로직
1. 변경 조항(c006)에서 출발하여 의존관계 엣지를 따라 도달 가능한 모든 조항 탐색
2. 영향 단계(hop) 기록: 직접 영향(1hop) → 간접 영향(2hop+)
3. 각 영향 조항에 대해 구체적 변경 필요 내용 서술
4. 위험 수준 분류

#### 출력 형식

```markdown
## 변경 영향 분석: 제6조 이자율 (LIBOR → SOFR)

### 핵심 요약
> 이자율 기준 변경은 총 **7개 조항**에 영향. Critical 2건, Major 3건, Minor 2건.

### 직접 영향 조항 (1단계)
| 조항 | 연결 유형 | 영향 내용 | 위험 수준 |
|------|----------|---------|---------|
| 제7조 (지급금액 산정) | LOGICAL_DEP (STRONG) | SOFR 기준 재산정 필요, 전환 스프레드(CSA) 반영 여부 결정 요 | Critical |
| 제11조 (기한이익상실) | CROSS_REF (STRONG) | 이자 미지급 기준금액이 변동되므로 EOD 트리거 금액 재확인 필요 | Critical |

### 간접 영향 조항 (2단계)
| 조항 | 경로 | 영향 내용 | 위험 수준 |
|------|------|---------|---------|
| 제15조 (해지) | c006→c011→c015 | EOD 발생 시 해지 권리 행사 범위에 영향 | Major |
| 제18조 (손해배상 한도) | c006→c007→c018 | 지급금액 기준 손배 상한 재계산 필요 | Major |

### 변경 불필요 확인 조항
- 제1조 (정의): "이자율"을 정의하지 않아 직접 영향 없음
- 제25조 (분쟁해결): 독립 조항, 영향 없음

### 권고 수정 순서
1. 제6조 수정 (이자율 기준 교체)
2. 제7조 산정식 수정 (CSA 스프레드 반영)
3. 제11조 EOD 금액 기준 재확인
4. 제15조·제18조 간접 영향 검토
```

## 주요 연결사항 요약 출력 (선택적 실행)

전체 계약서의 핵심 연결 허브(hub clause)를 식별하고 요약한다.

```markdown
## 계약서 핵심 연결사항 요약

### 허브 조항 (다수 조항에 영향을 미치는 핵심 조항)
| 순위 | 조항 | 유형 | 연결된 조항 수 | 비고 |
|------|------|------|--------------|------|
| 1 | 제1조 (정의) | DEFINITION | 14개 | 정의 용어 변경 시 전체 파급 |
| 2 | 제6조 (이자율) | FINANCIAL | 7개 | 금융조건 핵심 |
| 3 | 제8조 (선행조건) | CONDITION | 6개 | CP 충족 여부가 대부분 의무 발생 전제 |

### 취약 연결 (단방향 강의존 — 피의존 조항 변경 시 위험)
- 제11조 → 제6조 (STRONG): 제6조가 변경되면 EOD 기준 재검토 필수
- 제15조 → 제8조 (STRONG): 선행조건 미충족 해지 트리거 직결

### 고립 조항 (다른 조항과 연결 없음 — 독립 협상 가능)
- 제22조 (기밀유지), 제25조 (분쟁해결), 제26조 (통지)
```

## 출력 파일

| 파일 | 내용 |
|------|------|
| `/output/reports/dependency_map_[딜명].md` | 전체 의존관계 분석 보고서 |
| `/output/logs/dependency_graph_[딜명].json` | 기계 판독 가능 그래프 데이터 |
| `/output/reports/impact_[조항번호]_[딜명].md` | 특정 조항 변경 영향 분석 |

---

## 품질 기준

| 항목 | 기준 |
|------|------|
| 조항 파싱 커버리지 | 전체 조항 100% 분류 |
| 의존관계 탐지 | 명시적 교차참조 누락 0건 |
| 논리적 의존 탐지 | Critical 연결 누락 0건 |
| 영향 분석 완결성 | 변경 조항 기준 2hop 이내 전수 분석 |
| 위험 분류 정확도 | LLM 자기검증 후 Critical/Major/Minor 분류 |
